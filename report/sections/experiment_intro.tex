Datasets utilizados:

Se utilizaron datasets que contienen n animes, con M minutos disponibles y E energia disponible.
Cada anime poseé una q cantidad de capitulos disponibles, y b bono disponible por completar todos los capitulos.
Y cada capitulo tiene una t duracion en minutos, c costo de energia en cada capitulo y una satisfaccion v por ver el capitulo.

Cada caso de prueba tiene n cantidad de animes, cada uno con casos pequeños, medianos y grandes para probar.
